## Clean-checkout reference and consumer

On 2026-10-29, a fresh remote clone of published source `1fa654be73d582e9ae4778da0d757e9112a6bac1` configured and built the reference and consumer in separate Windows directories containing spaces. The consumer executable returned zero. The official-client smoke against the fresh reference exercised the negotiated revision and tool/resource/prompt flow. These checks validate the supporting instructions below; README remains outside this documentation pass.

Use PowerShell with Git, CMake 3.20+, VS 2022 C++ tools v143 14.44, Windows SDK 10.0.26100.0 and checksum-verified Node 24.22.1 first on this shell's PATH. Use fresh directory names and check each command's exit status before continuing. The source pin is available remotely; it does not depend on unpublished HEAD or these draft documents.

```powershell
git clone --no-checkout https://github.com/ptai-eng/synapse-mcp.git "Synapse checkout"
git -C "Synapse checkout" checkout --detach 1fa654be73d582e9ae4778da0d757e9112a6bac1
cmake -S "Synapse checkout" -B "Synapse reference build" -G "Visual Studio 17 2022" -A x64 -T "v143,version=14.44" "-DCMAKE_SYSTEM_VERSION=10.0.26100.0" -DSYNAPSE_MCP_BUILD_EXAMPLES=ON -DSYNAPSE_MCP_BUILD_TESTS=OFF
cmake --build "Synapse reference build" --config Debug --target native_status --parallel 2
cmake -S "Synapse checkout/tests/consumer" -B "Synapse consumer build" -G "Visual Studio 17 2022" -A x64 -T "v143,version=14.44" "-DCMAKE_SYSTEM_VERSION=10.0.26100.0"
cmake --build "Synapse consumer build" --config Debug --parallel 2
& ".\Synapse consumer build\Debug\synapse_consumer.exe"
```

The consumer requests C++17 as its parent default; linking `synapse::mcp` supplies C++23 to its executable. Its fixture also rejects examples/test leakage and checks propagated Unicode schema support. This is source-tree embedding through `add_subdirectory`, not an installed package test.

For the official-client smoke, install the pinned development tools, enable interop prerequisites and build the environment probe. The harness needs only these two targets; run the full CTest command only after building all test executables.

```powershell
npm --prefix "Synapse checkout/tests/interop" ci --ignore-scripts
cmake -S "Synapse checkout" -B "Synapse reference build" -DSYNAPSE_MCP_BUILD_TESTS=ON -DSYNAPSE_MCP_BUILD_INTEROP_TESTS=ON
cmake --build "Synapse reference build" --config Debug --target native_status synapse_interop_environment --parallel 2
$referenceBinary = (Resolve-Path "Synapse reference build/examples/Debug/native_status.exe").Path
$environmentProbe = (Resolve-Path "Synapse reference build/tests/Debug/synapse_interop_environment.exe").Path
$sourceRoot = (Resolve-Path "Synapse checkout").Path
$gitBinary = (Get-Command git).Source
$evidenceFile = [IO.Path]::GetFullPath("Synapse reference build/evidence/docs-client.json")
node "$sourceRoot/tests/interop/run-client.mjs" "$referenceBinary" "MSVC 19.44.35228.0" "$environmentProbe" "$sourceRoot" "$evidenceFile" "$gitBinary"
```
